Part 2: Critical Stock Reorder Analysis (SQL SUBQUERY)

Uses an inner query to filter records in an outer query using django.db.models.Subquery.

Outer Table medicine (Medicine model)
Inner Table (Subquery) inventory (Inventory model)
Business Logic Identify catalogue medicines whose stock quantity has reached or fallen below the branch reorder threshold.
Filter Condition medicine_id IN (SELECT medicine_id FROM inventory WHERE quantity_on_hand <= reorder_threshold)

Django ORM Implementation:

from django.db.models import Subquery, F

# Inner query: select medicine_ids needing replenishment
critical_ids = Inventory.objects.filter(quantity_on_hand__lte=F('reorder_threshold')).values('medicine_id')

# Outer query: retrieve medicine profiles matching the subquery ids
medicines_to_reorder = Medicine.objects.filter(medicine_id__in=Subquery(critical_ids))

Part 3: Supabase Database Architecture & Verification

Summary of relational tables, foreign key constraints, and SQL editor execution in Supabase.

Table: medicine Holds product catalogue records. Primary Key: medicine_id. Foreign Key: company_id → company.
Table: branch Holds physical branch locations. Primary Key: branch_id. Foreign Key: company_id → company.
Table: inventory Links medicines and branch locations. Foreign Keys: branch_id → branch and medicine_id → medicine.
